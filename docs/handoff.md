## 2. Включение конкурсного режима

```bash
cp .env.example .env
# .env:
# PUBLIC_VENTORME_MODE=competition
# PUBLIC_VENTORME_TEAM_ID=<официальный номер команды, строкой>
npm run build && npm run check:release
```
Затем выложить `dist/` на любой статический хостинг (Netlify/Vercel/Cloudflare Pages/GitHub Pages). Проверено на номере-образце `042`; `017` отклоняется как пример из кейса; без номера сборка падает намеренно.
