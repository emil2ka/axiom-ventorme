## 2. Найденные и исправленные проблемы редизайна

1. **Пустая зона вопросов**: фаза initial не рендерила QuestionPanel (стартовая карточка удалена по брифу) — панель теперь рендерится в initial и questions, первый выбор стартует опыт.
2. **Сетка hero** (named-areas сломали 12 колонок) — вернулись к явному размещению; у сцены убран min-height, вызывавший провал между текстом и CTA.
3. **Нативный вид кнопки-ссылки** «Посмотреть примеры без вопросов» — сброшен.
4. **Сцена**: тёмные запутанные ленты → переработаны кривые (чистые потоки без пересечений вне узла), материал из «зеркала» в серебро (metalness .45, env 1.5), ширина 0.32 (моб. 0.40), лёгкая крутка.
5. **Мобильная сцена бледная** (аудит S6): камера ближе (z 6.2), ленты шире, подписи компактнее — читается.
6. **Свечение узла доминировало** (аудит S6): эмиссия узлов 1.4→1.0, glow-спрайт ослаблен и уменьшен.
7. **Аудит S5, утечка RAF**: отложенный scroll-rAF после unmount мог перезапустить цикл на disposed-рендерере — отменяется, handle обнуляется, есть guard `disposed`.
8. **Аудит S5, потеря результата**: `openDemo` перезаписывал персональные `resultIds` — теперь demo не трогает персональный результат, `cancelEdit` возвращает к нему, `openDetail` валидирует по актуальному набору.
9. **Аудит S5, два status-сообщения**: лимит-сообщение и «Чтобы добавить…» одновременно — лимит сбрасывает `requestedCategory`.
10. **Аудит S5**: restart не сбрасывал сообщение о лимите — сброшен.
11. **Аудит S5, lint**: неиспользуемый импорт в store удалён.
12. **«Висячий союз и»** в подзаголовке hero — неразрывный пробел.
13. **Мобильный hero не вмещал подпись без регистрации** — уплотнены подписи сцены и отступы; вся композиция в кадре 390×844.

## 3. Честные ограничения

- Браузерные проверки — Chromium headless (SwiftShader для WebGL). Реальные iOS/Android GPU, Safari/Firefox не проверялись; производительность на слабом телефоне не измерена.
- Запись движения невозможна в этой среде (screencast+ffmpeg падает); доказательство — журнал переходов и кадры состояний (см. §1).
- Lighthouse/полевые Web Vitals не запускались; проверены вес бандлов и поведение (пауза вне экрана, DPR-лимит, idle-загрузка three).
- 200% zoom проверен рефлоу-эквивалентами 320/360 CSS px; полноценный браузерный zoom на реальном устройстве рекомендован командой.
- Тексты о Ventorme остаются по публичному описанию; фактический путь онбординга — на команде.
