## 2. Найденные и исправленные проблемы

1. **`<dialog>` не центрировался** — глобальный сброс `* { margin: 0 }` перебивал `dialog { margin: auto }`. Исправлено в `global.css`.
2. **Disabled-кнопки выглядели активными** — добавлен стиль `.btn:disabled`.
3. **Фокус при смене шага прокручивал страницу под фиксированную шапку** — фокус переведён на `focus({ preventScroll: true })`.
4. **Аудит S5:** гонка фокуса при старте с выбранного интереса (флаг фокуса гасился на idle-рендере) — фокус ставится только при существующей цели.
5. **Аудит S5:** `loadJourney()` не валидировал структуру — добавлена полная проверка и нормализация (битый JSON не ломает сценарий).
6. **Аудит S5:** режим «примеры без вопросов» мог смешиваться с персональным результатом при частичных ответах — введён явный флаг `skipped` в состоянии.
7. **Аудит S5:** `takePendingCategory()` терял интерес при уже собранном результате — категория возвращается обратно.
8. **Аудит S5:** осознанно оставлен `throw` при competition без номера — это защита выпуска (сборка падает), см. handoff.
9. **Сборка падала** на импортах `./RegistrationLink` без расширения `.astro` — исправлено.
10. **`check:release` давал ложные срабатывания** на JS-константу базы и обёртку шаблонной строки — проверка URL ограничена HTML, JS проверяется только на заглушки.
11. **Hero H1 ломался на 4 строки** — перекомпонована сетка (7/5 колонок, `clamp(56px, 6vw, 84px)`), теперь две смысловые строки «Твоё будущее / ещё не написано.».
12. **Аудит S6:** под открытым мобильным меню просвечивал hero — панель меню сделана полностью непрозрачной.
13. **Аудит S6:** порядок блоков карточки и диалога различался — диалог повторяет порядок карточки по цели Q3.
14. **Аудит S6:** слабый backdrop диалога — усилен (0.82 + blur).
15. **Аудит S6:** подписи компаса прижимались к краям на 320–390 px — уменьшен радиус подписей.

- Полевые Web Vitals и Lighthouse-прогон: не выполнялись (доступна только лабораторная оценка веса выше; заявленные цели LCP/INP/CLS остаются целями).
- Автоматический прогон axe/WAVE: не выполнялся; доступность проверена кодом + клавиатурными сценариями (Escape, возврат фокуса, skip-link, семантика input/dialog/details).
- Полный клавиатурный проход «только Tab» по всей странице — рекомендован как ручной шаг (см. handoff).

- Тексты о Ventorme — по публичному описанию; фактический путь онбординга не проверялся командой.
