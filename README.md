# Axiom (Ventorme)

Пиксельный лендинг Ventorme для Hacknext. Прокрутка управляет путешествием одного школьника между учебными островами. Следующий остров расположен ниже и немного в стороне: герой спускается на него, камера идёт следом. Общая карта появляется только в финале. Белый фон сохраняется во всех сценах.

## Запуск

Нужен Node.js 22.x (не ниже 22.12).

```sh
npm ci
cp .env.example .env
npm run dev -- --host 127.0.0.1 --port 4321
```

Открой http://127.0.0.1:4321/. Astro 7 запускает сервер в фоне. Управление: `npm run dev -- status`, `npm run dev -- logs`, `npm run dev -- stop`.

## Деплой в Vercel

Импортируй `emil2ka/axiom-ventorme`, ветка `main`, в [Vercel](https://vercel.com/new). Корень проекта — корень репозитория. `vercel.json` задаёт Astro, `npm ci`, выпуск в `dist` и проверку реферальной ссылки команды 106. Переменные для текущего конкурсного выпуска уже заданы в команде сборки; локальный `.env` не требуется. Node.js 22.x закреплён в `package.json`.

Пошаговая инструкция: [docs/vercel-deploy.md](docs/vercel-deploy.md). Мобильная проверка: [docs/mobile-qa.md](docs/mobile-qa.md).

## Путешествие

- Старт: слоган, большой остров с указателем и герой, который смотрит на посетителя, моргает и машет.
- Выбор профессии: учебный павильон с компьютером, микроскопом и творческим столом; компас показывает направление.
- Университет: белый кампус с синими крышами, фонтаном и дорожкой; герой подходит ко входу, вода в фонтане движется.
- Подготовка: библиотека, подход к столу и раскрытие книги по 16 сгенерированным кадрам.
- Гранты и стипендии: университетский центр поддержки студентов; на столе раскрывается папка с сертификатом.
- Документы: приёмная комиссия с папками и учебным гербом вместо почты; документы собираются в папку.
- Финал: немного уменьшенная общая карта, возвращение героя на стартовый остров и приглашение пройти бесплатный мини-профтест в Ventorme.

Каждый остров использует одно и то же изображение в общем и крупном плане. Изображение не подменяется при приближении. Для текущих рисунков используются lossless WebP; исходные PNG сохранены. Прокрутка запрашивает следующую остановку. Приседание, отталкивание, полёт и посадка заканчиваются по времени, даже если перестать листать. Затем герой подходит к предмету и завершает действие. При быстрой прокрутке выбирается последняя запрошенная локация без длинной очереди. Направление героя соответствует траектории. Добавлены отдельные циклы боковой и задней ходьбы.

Один жест прокрутки запускает один законченный эпизод. До завершения прыжка и действия прокрутка блокирует следующий шаг, накопленный ввод отбрасывается. Навигация по этапам позволяет перейти к нужной сцене. Регистрация доступна с первого экрана и в верхней навигации. Режим уменьшенного движения показывает спокойную последовательность иллюстраций и текста.

Это демонстрационный лендинг. Персональный подбор, тесты и работа с документами продолжаются на официальной платформе. Здесь не создаётся аккаунт и не отправляются заявления.

## Основные файлы

- `src/components/pixel/ScrollJourney.tsx` — текущая главная страница и управление прокруткой.
- `src/components/pixel/journeyModel.ts` — содержание локаций и типы.
- `src/components/pixel/journeyPlayback.ts` — геометрия карты, камера и воспроизведение законченных эпизодов.
- `src/components/pixel/NativeStation.tsx` — мебель и движущиеся предметы в сгенерированных атласах.
- `src/components/pixel/journey.css` — композиция, адаптивность и интерфейс.
- `src/components/pixel/HeroSprite.tsx` — атласы персонажа и выбор кадров по времени или прогрессу.
- `public/journey/` — новые прозрачные иллюстрации и атласы.
- `src/config/campaign.ts` — ссылка команды.

Промпты новых островов: [docs/journey-medium-assets.json](docs/journey-medium-assets.json). Атласы предметов и героя: [docs/journey-assets-v2.json](docs/journey-assets-v2.json). Реализация и проверка: [docs/scroll-journey.md](docs/scroll-journey.md). Предыдущие компоненты и рисунки сохранены в проекте; главная страница подключает `ScrollJourney`.

## Проверки

```sh
npm run build
npx --no-install tsc --noEmit
npm test
npm run check:release
```

Тесты путешествия проверяют непрерывность героя и камеры на границах сцен, видимость героя в полёте на компьютере и телефоне, посадку на поверхность и повторное получение состояния при обратной прокрутке. Визуальная проверка выполняется дополнительно в браузере.
