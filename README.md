# Axiom (Ventorme)

Интерактивный пиксельный лендинг Ventorme для Hacknext. Пять тематических островов и маленький центральный остров с одним путешественником. Белый фон и сине-белая палитра.

![Pixel landing](docs/screenshots/pixel-landing-current.jpg)

[Карта островов](docs/screenshots/pixel-map-current.jpg) · [Библиотека](docs/screenshots/library-current.jpg)

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 4321
```

Открой http://127.0.0.1:4321/. Astro 7 запускает сервер в фоне:

```sh
npm run dev -- status
npm run dev -- logs
npm run dev -- stop
```

## Что работает

- Пиксельные острова с прежними зданиями из одобренного концепта; края и детали слегка доработаны: направление, университет, подготовка, финансирование, заявка.
- Первый экран: слоган слева, крупный стартовый остров справа и пять прежних островов сверху. Прокрутка плавно уменьшает стартовый остров и раскрывает карту; прокрутка обратно возвращает вступление.
- Один герой смотрит на нас на старте и карте, дышит, моргает и машет. Для прыжка выбирает лицо, спину или профиль по направлению полёта. Внутри острова поворачивается к объекту.
- Приседание, отталкивание, полёт по непрерывной параболе, мягкое приземление с восстановлением и ходьба. Все позы выровнены по одной точке опоры.
- Камера приближает выбранный остров; иллюстрация карты плавно смешивается с детальной сценой. Общий белый фон и герой сохраняются в DOM.
- Прежние маленькие острова сохранены. Большие сцены снова используют проработанные здания; чётче прорисованы окна, крыши и дорожки. Библиотека упрощена до уютного корпуса с книгами, скамейкой и небольшим двором.
- Кнопки, подписи островов, действие у входа и карточка продолжения оформлены в единой сине-белой палитре. Действие у входа не закрывает героя.
- Внутри можно нажать на дорожку или на объект. Герой подходит к точке; открывается описание и переход на платформу Ventorme.
- Возвращение отдаляет камеру и возвращает героя на центральный остров прыжком.
- Адаптивная композиция, клавиатурный выбор, системное уменьшение движения и ручной переключатель.
- Целые острова плавно парят на ±3 пикселя с разными периодами. Герой следует центральному островку. Во время прыжка и входа парение приостанавливается. Деревья и камни отдельно не двигаются, поэтому нет разрывов.

Это лендинг. Подбор вуза, тесты и регистрация продолжаются на официальной платформе; здесь эти функции не имитируются.

## Основные файлы

- `src/components/pixel/UnifiedLanding.tsx` — сцена, камера, последовательность прыжка и переходы.
- `src/components/pixel/HeroSprite.tsx` — 48 кадров в трёх атласах: приветствие, три направления прыжка и ходьба.
- `src/components/pixel/IslandPosition.tsx`, `intro.css` — прокрутка от вступления к карте.
- `src/components/pixel/hero-atlas-meta.json` — измеренные центры и опорные точки кадров.
- `src/components/pixel/worlds.ts` — содержание островов.
- `src/components/pixel/unified.css`, `pixel.css` — интерфейс и адаптивность.
- `public/map-islands/*-polished.png` — прозрачные спрайты карты с исправленными краями. Прежние SVG сохранены рядом.
- `public/islands/*-refined.png` — выбранные детальные внутренние сцены с нативной прозрачностью, 1672 × 941. Исходные PNG сохранены рядом. Масштаб камеры ограничен, чтобы не растягивать их чрезмерно.
- `public/characters/hero-atlas.png` — атлас персонажа: 6 столбцов × 4 ряда.
- `src/config/campaign.ts` — ссылка регистрации и атрибуция команды.

Происхождение изображений и спецификация генерации: [docs/pixel-assets.md](docs/pixel-assets.md). Компоненты прежних вариантов остаются в исходниках, но главная страница подключает только UnifiedLanding.

## Проверки

Перед сборкой останови dev-сервер, чтобы два процесса Vite не оптимизировали зависимости одновременно.

```sh
npm run dev -- stop
npm run build
npx --no-install tsc --noEmit
npm test
npm run check:release
```

Тесты проверяют логику рекомендаций, состояние, SSR и кампанию. Визуальные переходы дополнительно проверяются в браузере на компьютере и телефоне.

## Конкурсная ссылка

Официальная ссылка команды 106: `https://ventorme.ai/register?utm_source=hacknext&utm_campaign=team-106`. Локальный `.env` уже настроен; в свежей копии сначала скопируй `.env.example` в `.env`:

```sh
cp .env.example .env
npm run build
npm run check:release
```

Настройки есть в `.env.example`. Секреты и локальные `.env` в репозиторий не входят.

Без `.env` используется preview без командной атрибуции. Проверка выпуска читает `.env`, как локальная сборка; переменные из командной строки имеют приоритет.

## Кадры для видеоперехода

[Промпт на 4 секунды](docs/transition-prompt.md). Кадры без персонажей можно снова получить через `/transition-frame?world=university&view=map` и `/transition-frame?world=university&view=inside`. Допустимые world: direction, university, preparation, funding, application. Страница предназначена для экспорта референсов без интерфейса; она не подключена к пользовательской навигации. Промпты доработки островов: [docs/map-polish-prompts.md](docs/map-polish-prompts.md) и [сцены / персонаж](docs/intro-and-simple-scene-prompts.md).

Референсы экспортированы в 1280 × 720. Настоящие видео пока не созданы и не подключены: действующий переход использует камеру и смешивание двух PNG. Для видео нужен отдельный ролик на 4 секунды, без героя и интерфейса; герой продолжает анимироваться отдельным слоем.
